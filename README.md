# Aula Digital

Web inicial para organizar apuntes, materiales y recursos docentes.

## Archivos
- `index.html`: estructura y contenido.
- `style.css`: diseño responsive y paleta corporativa.
- `script.js`: búsqueda de asignaturas y menú móvil.

## Publicar con GitHub Pages
1. Abre **Settings → Pages** en este repositorio.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
4. Espera a que GitHub Pages publique la web.

## Paleta corporativa
- Azul marino: `#17324D`
- Naranja: `#FF6B35`
- Fondo general: `#F7F8FA`
- Tarjetas: `#FFFFFF`
- Texto secundario: `#66717C`
- Bordes: `#E4E7EB`

Las páginas de asignatura y los documentos se irán incorporando más adelante.
